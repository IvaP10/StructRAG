▤ StructRAG

Ask questions about your PDFs

StructRAG reads dense documents — financial filings, papers, reports — and answers questions with the page it took each fact from.

This is a demo running on a personal API budget, so usage is capped. Documents you upload are held only for your session and are discarded when it expires.
